# Phase G report

Phase G adds immutable source-aware corpus releases, source-quality registry records, sealed test-release creation, tokenizer/learning-curve diagnostics, resource preflight, controlled model/context scaling, a bounded cognitive contract loop, curation/replay primitives, and an immutable executable-evaluation framework.

The measured candidate is a fresh 8,426,368-parameter ULTRON model, trained for 102,400 packed tokens. It reached validation loss 2.868 and a sealed-test loss 3.050. These are token-prediction measurements, not evidence of general intelligence or broad task competence.

The corpus release `ultron-corpus-0.3.0-phase-g-curated-v3` contains 67 accepted documents and 232,688 tokenizer tokens. It has source-level train/validation/test isolation, but its report flags general-domain dominance and starvation in mathematics, science, engineering, and instruction. The validation partition is also too narrow for a promotion decision.

All fifteen capability categories are `INSUFFICIENT_EVIDENCE`: the suite is real and immutable, but a local ULTRON generation adapter is not yet implemented, so no learned-model outputs were substituted with deterministic answers. The Phase G model is therefore rejected for promotion. There is no promoted Phase G model.

The bounded cognitive task that completed used a deterministic contract test double plus an allowlisted local inspection tool. It verifies lifecycle/schema/tool-boundary plumbing only; it is not a learned foundation-model task result.
