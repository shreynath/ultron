# Datasets

Corpus releases are immutable and store source-group split manifests, document hashes, quality report, duplicate statistics, category/license composition, and warnings. `source_group_balanced` retains source-level isolation while approximating partitions by source character mass. Test splits can be copied once into immutable evaluation releases.

Quality scores measure data suitability signals, not truth. The source registry records authority/provenance/structure/licensing and other explainable factors separately from evidence validation.
