# Continual learning

Experiences are durable and sanitized. A completed task can create a learning event, but it cannot directly alter weights. The allowed path is experience, quality/provenance review, explicit corpus release, candidate training, evaluation comparison, and a separate promotion decision.

The current implementation has not authorized automatic corpus admission from web knowledge or user memory.
# Phase G update

Experiences now have an explicit curation gate before training use: provenance, privacy, duplicate, verification, contamination, and quality checks. Replay mixtures must retain historical foundation data. The completed Phase G cycle is a controlled contract-record curation exercise only, not evidence that a model learned from experience.
