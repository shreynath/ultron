# Phase L Capability Emergence

Capability rows are model-only and may not include retrieval, tools, memory,
web access, answer repair, or another model.  At this point the timeline has
only the Phase J baseline and Phase K execution pilots; Phase L capability
values are `INSUFFICIENT_EVIDENCE` until qualified-corpus checkpoints exist.

The required comparison records parameter count, training tokens, held-out
loss, EOS rate, repetition, entropy, native generation, and predefined
capability-suite outcomes.  Loss alone never establishes capability.
