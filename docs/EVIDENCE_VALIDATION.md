# Evidence validation

The research engine classifies source types, extracts bounded candidate claims, attaches passages as evidence, groups corroboration by domain, detects simple polarity conflicts, and retains uncertainty. Supported world knowledge includes source identities and freshness metadata. Contradictions are preserved instead of silently selecting one claim.

These heuristics are measurable but not a universal truth oracle. Confidence derives from defined source and corroboration rules, not model self-report.
