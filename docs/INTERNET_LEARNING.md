# Internet learning

The bounded research engine uses controlled discovery and public HTTP fetches, validates DNS and redirects, bounds size/time/concurrency, and persists source, claim, evidence, contradiction, freshness, and provenance records. Search discovery is not a fact. Fetched text remains untrusted data.

Verified web knowledge is stored for retrieval. It does not become model weights. Any future training candidate needs an explicit curation, license, privacy, quality, and dataset-release boundary. No cloud language model is involved in acquisition or deterministic evidence validation.
