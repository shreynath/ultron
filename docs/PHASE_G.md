# Phase G capability scaling and grounding

Phase G is a measured expansion of the local, random-init ULTRON program. Its pipeline is: curated source registry → deterministic quality/release processing → source-isolated train/validation/test → tokenizer and training diagnostics → measured scaling and sustained training → sealed evaluation → promotion gate.

Foundation-model outputs remain subordinate to the executive cognitive layer, retrieval/evidence boundaries, allowlisted tools, verification, and persistent bounded task state. Web content is untrusted external data; it never receives instruction authority or training authority without an explicit curated release.

The phase intentionally preserves negative evidence. A larger corpus and lower loss do not establish capability. See [PHASE_G_REPORT.md](/Users/shreyaannath/Programming/Ultron/docs/PHASE_G_REPORT.md) for the actual measurements, rejection decision, and current bottleneck.
